📖 Komplett guide

Allt du kan göra med Fitcoon

Fitcoon är din kompletta träningsdagbok — styrketräning, kroppsviktsträning, kondition — 100 % privat och offline. Här är varje funktion och hur du använder den.

🌐
🏋️ Träning 🧰 Min utrustning 🤸 Kroppsviktsträning 📈 Uppföljning & utveckling 🏃 Kondition & utomhus 🩺 Hälsa & återhämtning 🎯 Program & coaching 🤝 Socialt & motivation 🎨 Anpassning 🔒 Data & integritet
🏋️

Träning

Skapa, generera och starta dina styrke- och kroppsviktspass.

🗂️ Program

Dussintals färdiga program (styrka, muskeluppbyggnad, definition, nybörjare, styrkelyft, kroppsviktsträning…), över flera veckor.

Fliken Program → välj → starta

🏋️ Pass

Dina sparade pass + färdiga pass. Filtrera efter muskel, längd, ursprung och sammanhang Kroppsvikt / Gym / Hemma. NEW

Fliken Pass → filtrera → starta

⚡ Generator

Ett skräddarsytt pass med ett tryck: välj tid, utrustning och muskler, så sätter appen ihop träningen.

Pass → Generera ett pass

🎬 Pågående pass

Uppföljning set för set, automatisk vilotimer, förifyllning av senaste vikten, uppvärmningsset, rekord som firas direkt.

Under passet

🔊 Handsfree-läge för gymmet

Stora knappar, skärmen tänd, röstuppläsning av set och vila — perfekt mitt i passet.

I pass → gymläge

⚡ WOD och finishers

Generator för AMRAP- / EMOM- / Tabata- / For Time-cirklar, och 10 guidade finishers för att avsluta starkt.

Guide → WOD / Finishers

🧘 Rörlighet

8 guidade rutiner för rörlighet och stretching.

Guide → Rörlighet

➕ Fritt pass

Starta utan mall och lägg till dina övningar allt eftersom.

Start / Pass → Fritt pass
🧰

Min utrustning

Ange din utrustning exakt: program och övningar anpassar sig efter vad du faktiskt kan göra.

🎯 Detaljera din utrustning

Skivstänger (med sin vikt), max vikt i viktskivor, hantlar (min/max), kettlebells, maskiner (rullgardinsmeny), gummiband (styrka). Du kan till och med lägga till foton på din utrustning.

Guide → Min utrustning

🔎 Smart filter

Inget markerat = du ser allt. Markerad utrustning = endast genomförbara övningar och program visas. Allt går att ändra när som helst.

Min utrustning → Filtrera
🤸

Kroppsviktsträning

En riktig kroppsviktsdel: progressiva program och pass utan utrustning.

📋 Dedikerade program

Nybörjare, medel, avancerad, street workout (räcke & dips), skills (L-sit, muscle-up), säte, mage, explosivt, rörlighet, 30 dagars armhävningar…

Program

🔥 Fristående pass

Tryckövningar hemma, pull-ups & rygg, core 10 min, ben utan utrustning, EMOM, pliometrisk HIIT, kondition hemma… från 10 till 45 min.

Pass → filter Kroppsvikt
📈

Uppföljning & utveckling

Se dina framsteg ur alla vinklar.

📈 Snabbset under dagen

Logga ett set av en övning med 2 tryck, utan att skapa ett pass (”15 armhävningar i morse”). Regelbundna övningar får en egen utvecklingskurva.

Start → Snabbset

📊 Utveckling per övning

Kurva över uppskattat 1RM och belastning över 4 / 8 / 12 veckor, repsrekord, utveckling ”+X på 3 månader”.

Framsteg → ett rekord

🏆 Rekord & 1RM

Automatiska rekord per övning, uppskattat 1RM (Epley), rekord per antal repetitioner.

Framsteg

🗺️ Muskelkarta & radar

Se vilka muskler du tränar mest, din muskelbalans och återhämtningen per grupp.

Framsteg / Guide

📅 Komplett historik

Varje pass i detalj, redigerbart, med tips inför nästa gång.

Framsteg → Historik

⚖️ Kropp & foton

Vikt, midje-/arm-/låromfång, BMI och före/efter-foton.

Guide → Min kropp / Foton

Inställningar → aktivera • sedan vid start

Guide → Kosttillskott

😴 Återhämtning

Data & integritet

Din data tillhör dig — på riktigt.

🔒 100 % lokalt & offline

Ingen data skickas till internet, inget konto krävs, ingen reklam. Allt stannar på din telefon.

Som standard

🛟 Säkerhetskopiering mot dataförlust

Välj en mapp (Drive, Nedladdningar…) dit dina säkerhetskopior kopieras automatiskt och överlever avinstallation. Återställning med ett tryck vid första starten.

Inställningar → Mapp för säkerhetskopior

🔁 Uppdateringar utan dataförlust

Din data bevaras vid varje uppdatering, även om du hoppar över flera versioner.

Automatiskt

📤 Export

Exportera din data som CSV, JSON eller en komplett PDF-rapport.

Guide → Export
